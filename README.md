# MCS-2602 Student Hub + AITU Campus Map

Готовый статический сайт без сборщика и внешних зависимостей.

## Запуск

Откройте `index.html` в современном браузере или разместите всю папку на любом статическом хостинге (GitHub Pages, Netlify, Vercel, Nginx).

Для локального запуска через сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Что улучшено

- Полностью переработан UI/UX расписания для desktop и mobile.
- Карта корректно сохраняет пропорции SVG и больше не растягивается.
- Добавлен режим «Весь этаж» с одновременным просмотром C1.1, C1.2 и C1.3.
- Добавлены отдельные режимы корпусов и быстрый переключатель этажей.
- Полнотекстовый поиск по 264 кабинетам и алиасам, включая номера без суффиксов P/L/K.
- Автоматический переход к нужному корпусу и этажу с подсветкой кабинета.
- Масштабирование колесом/кнопками, панорамирование перетаскиванием и сброс вида.
- Полноэкранный режим карты и открытие карты в отдельной вкладке.
- Кликабельные кабинеты на SVG-планах.
- Поддержка клавиатуры, focus-состояний, reduced motion и системной тёмной темы.
- Карта из расписания открывает нужную аудиторию напрямую.

## Структура

- `index.html`, `style.css`, `script.js` — Student Hub и расписание.
- `aitumap/` — самостоятельная интерактивная карта.
- `aitumap/plans.js` — встроенные планы и индекс аудиторий для автономной работы.
- `aitumap/plans/` — читаемые исходные SVG-планы всех 9 комбинаций корпус/этаж.
