# CS-2604 Student Hub + AITU Campus Map

Минималистичный статический сайт расписания с интерактивной картой кампуса. Сборщик и внешние зависимости не требуются.

## Запуск

Для корректной работы откройте проект через локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Что улучшено

- Упрощена визуальная иерархия, унифицированы компоненты и отступы.
- Полностью адаптивный интерфейс расписания и карты.
- Карта загружается только при открытии, ускоряя старт главной страницы.
- Надёжное вычисление времени Алматы через `Intl.DateTimeFormat`.
- Делегирование событий и точечное обновление статуса вместо частого полного рендера.
- Поиск кабинетов с клавиатурной навигацией и нормализацией коротких номеров.
- Масштабирование относительно курсора, панорамирование и сброс вида.
- Состояние выбранного дня сохраняется локально; выбранный кабинет отражается в URL.
- Напоминания работают при открытой вкладке и честно сообщают об ограничении браузера.
- Улучшены focus-состояния, семантика, ARIA, размеры интерактивных зон и reduced motion.
- Удалены экспериментальные дублирующие файлы и служебная папка `.git` из поставки.

## Структура

- `index.html`, `style.css`, `script.js` — расписание.
- `aitumap/index.html`, `map.css`, `map.js` — карта.
- `aitumap/plans.js` — встроенные SVG и индекс кабинетов.
- `aitumap/plans/` — исходные SVG-планы.
